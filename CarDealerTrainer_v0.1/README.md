# CFS23 Trainer v0.1

Чит-тренер для **Car For Sale Simulator 2023** (только одиночная игра).
Работает через IL2CPP API + MinHook. Не содержит обходов античита и не предназначен для мультиплеера.

> Дисклеймер: используйте только в своей копии одиночной игры. Репозиторий/архив не содержит
> файлов самой игры, метаданных или дампов — только код тренера.

## Возможности

| Пункт меню | Описание |
|---|---|
| Infinite money | Ставит `CashManager.cash = 999 999 999`. Работает даже в главном меню. |
| BHop / auto jump | Автопрыжок на пешем персонаже. |
| Surf boost | Ускорение при скольжении по склонам/поверхностям. |
| Auto strafe | Поворот view/yaw по направлению скорости. |
| Foot speed | Множитель скорости ходьбы (x1.8 … x12). |
| Car speed | Множитель скорости авто (x2 … x50). |
| Fly / noclip | Полёт пешего персонажа: WASD + Space/Ctrl. |
| ESP cars | Рамки и дистанция до машин через GDI-оверлей. |
| No fog | Отключает туман (`RenderSettings.fog`). |
| FOV | 80 / 95 / 110 / 130. |
| Time scale | 1x / 0.5x / 2x / 0.1x. |

## Сборка

1. Откройте `build.bat` и, если нужно, поправьте путь `VCVARS` к вашему Visual Studio.
2. Запустите `build.bat` из этой папки.
3. Готовые файлы: `bin\CarDealerCheat.dll` и `bin\Injector.exe`.

## Использование

1. Запустите игру и дождитесь загрузки.
2. Запустите `bin\Injector.exe` (или `Injector.exe "путь\к\CarDealerCheat.dll"`).
3. В игре нажмите **INSERT** — откроется меню.
4. **Стрелки ↑/↓** — выбор, **Enter** — переключить/применить.
5. **INSERT** — закрыть меню.

Лог работы: `CFS23_cheat.log` в папке игры (рядом с `GameAssembly.dll`).

## Обновления игры

Если после обновления игры хуки не встанут, в `offsets.txt` можно переопределить 4 RVA
(`GameAssembly.dll` + RVA). Порядок строк указан в самом файле. По умолчанию используются
значения для этой версии игры:

```
FirstPersonMovement.Update  0x674190
FirstPersonMovement.FixedUpdate 0x673630
CarController.FixedUpdate   0x7871C0
CarController.Update        0x7897F0
```

Строки, начинающиеся с `#`, игнорируются.

## Состав архива v0.1

- `src/Cheat.cpp`, `src/Injector.cpp` — исходники
- `include/MinHook.h`, `lib/libMinHook.x64.lib` — вендорированный MinHook v1.3.4 (MIT)

- `offsets.txt` — RVA для этого билда игры
- `bin/CarDealerCheat.dll`, `bin/Injector.exe` — готовые бинарники для GitHub Release

- `.gitignore` — чтобы в репозиторий не попали `bin/` и логи

## Примечания

- `money` применяется фоновым потоком через статическое поле — поэтому работает в главном меню.
- Остальные визуальные/физические фичи применяются в игровых хуках, то есть в геймплее.
- Оверлей — отдельное GDI-окно с `WS_EX_LAYERED | WS_EX_TRANSPARENT`, не перехватывает ввод.
- При перезапуске игры DLL нужно инъектить заново (DLL блокируется живым процессом).
