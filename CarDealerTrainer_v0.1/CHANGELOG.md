# Changelog

## v0.1

- First public-ready build.
- Money cheat now applies from a background thread via `CashManager.cash`,
  so it also works in the main menu.
- Hooks for foot/car physics: bhop, surf boost, auto strafe, foot speed,
  car speed, fly/noclip.
- GDI overlay menu (INSERT) and ESP boxes for cars.
- Visuals: no fog, configurable FOV, far clip plane, time scale.
- `offsets.txt` support with comment lines.
- Vendored MinHook v1.3.4 and MSVC build script.
